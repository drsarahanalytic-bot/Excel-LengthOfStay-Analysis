# Excel Project: Hospital Length of Stay Analysis

## Problem Statement
Analyze hospital length of stay data to identify factors affecting patient stay duration, such as gender and dialysisrenalendstage.

## Tools Used
- Microsoft Excel (Data Cleaning, Pivot Tables, Charts, Conditional Formatting)

## Analysis Steps
1. Cleaned and prepared the dataset (removed duplicates, handled missing values, corrected data types).
2. Created Pivot Tables to calculate average length of stay by:
   - Gender
   - Dialysisrenalendstage
3. Built visualizations:
   - Bar Chart (Average Length of Stay by Gender)
   - Column Chart (Average Length of Stay by Dialysis)
   - Pie Chart (Patient Distribution by Gender)
4. Applied Conditional Formatting to highlight high values.
5. Assembled a dashboard combining all visualizations.

## Key Results
- Average length of stay is 4 days.
- Patients with dialysisrenalendstage have longer stays (6 days vs 4 days).
- Male patients stay slightly longer than female patients.
- The dataset is balanced between males and females.

## Files
- `Data/` – Source data (LengthOfStay.csv).
